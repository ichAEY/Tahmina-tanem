# Tahmina — TANEM

Сайт Тахмины использует тот же стабильный визуальный шаблон, что и сайт Нонны.

## Принцип

Дизайн, адаптив, блоки и механика берутся из зафиксированной версии `ichAEY/claytone-current`.
Клиентские данные Тахмины лежат отдельно в `site-data.mjs`.

Шаблон зафиксирован на commit:

`ce1bd42b44e76e1851af9e069c4cbcf06fc8eac2`

Поэтому будущие изменения сайта Нонны сами по себе сайт Тахмины не изменят.

## Что менять для Тахмины

`site-data.mjs`:
- имя и позиционирование;
- контакты;
- адрес и график;
- ссылки на запись и Яндекс Карты;
- услуги и цены;
- отзывы;
- SEO.

Фотографии:

`tahmina/assets/images/`

- `hero.jpg`
- `master.jpg`
- `logo.jpg`
- `portfolio/01.jpg` ... `portfolio/13.jpg`

## Публикация

`.github/workflows/pages.yml` автоматически:
1. получает зафиксированный шаблон Нонны;
2. подставляет `site-data.mjs` Тахмины;
3. копирует фотографии Тахмины;
4. собирает тот же Next.js сайт;
5. публикует результат через GitHub Pages.

Для GitHub Pages в Settings → Pages источник должен быть `GitHub Actions`.
