# Tahmina — TANEM

Сайт Тахмины на базе простого шаблона TANEM.

## Что менять для клиента

Почти весь контент находится в одном файле:

`site-data.js`

Там меняются:
- имя и позиционирование мастера;
- адрес, график и телефон;
- ссылки на запись, Telegram и Яндекс Карты;
- услуги и цены;
- отзывы;
- фотографии портфолио.

## Фотографии

Текущие изображения находятся здесь:

`tahmina/assets/images/`

Основные файлы:
- `hero.jpg` — главный экран;
- `master.jpg` — блок «О мастере»;
- `logo.jpg` — логотип;
- `portfolio/01.jpg` ... `portfolio/13.jpg` — работы.

## Что обычно не трогать

- `app.js` — структура и поведение сайта;
- `styles.css` — дизайн и адаптив;
- `index.html` — SEO и подключение файлов.

Так следующий сайт можно выпускать в основном заменой `site-data.js` и фотографий, без полной переделки кода.
